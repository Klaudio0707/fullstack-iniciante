# 🚀 fullstack-iniciante

## 📋 Sobre o Projeto

Este repositório foi criado para documentar e armazenar minha jornada de aprendizado no desenvolvimento de software, com foco em me tornar um desenvolvedor Full Stack.

O objetivo é construir uma base sólida, começando pelos fundamentos da programação e da web, e evoluindo para a integração de sistemas completos. O repositório está organizado de forma cronológica, com uma pasta dedicada para cada semana de estudo.

---

## 🛠️ Tecnologias e Ferramentas

Para esta fase inicial do aprendizado, estou utilizando:

*   **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)** - O "cérebro" da web (estudos atuais).
*   **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML)** - A estrutura dos sites (próximos passos).
*   **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS)** - O estilo e visual dos sites (próximos passos).
*   **[Node.js](https://nodejs.org/pt-br/)** - Ambiente de execução para rodar JS no computador.
*   **[Visual Studio Code](https://code.visualstudio.com/)** - Meu editor de código de preferência.
*   **[Git](https://git-scm.com/) / [GitHub](https://github.com/)** - Para controle de versão e portfólio.

## 🚀 Como Rodar os Exercícios

Atualmente, estamos focado em JavaScript para terminal (rodando no computador). Para rodar os meus códigos, você precisará:

1.  Ter o **[Node.js](https://nodejs.org/pt-br/)** instalado.
2.  Clonar este repositório:
    ```bash
    git clone [https://github.com/Klaudio0707/fullstack-iniciante.git](https://github.com/Klaudio0707/fullstack-iniciante.git)
    ```
    *(Substitua SEU-USUARIO pelo seu nome no GitHub)*
3.  Navegar até a pasta do arquivo que deseja rodar (ex: `aula1-JavaScript`):
    ```bash
    cd Semana01-JavaScript
    ```
4.  *(Opcional: Se o arquivo usar dependências como o `prompt-sync`)* Instale as dependências:
    ```bash
    npm install
    ```
5.  Rodar o arquivo usando o Node:
    ```bash
    node nome-do-arquivo.js
    ```
